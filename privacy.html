プライバシーポリシー

最終更新日：2026年11月6日

Tier Shorts（以下「本アプリ」）は、運営者本人が自分の YouTube チャンネルへ動画を投稿するための個人用アプリです。

取得する情報

本アプリは、運営者本人の Google アカウントによる認証（OAuth）で、YouTube への動画アップロード権限のみを取得します。それ以外の個人情報は取得しません。

情報の利用

取得した権限は、運営者本人が所有するチャンネルへ動画をアップロードする目的にのみ使用します。

第三者への提供

認証情報および取得したデータを、第三者に提供・販売・共有することはありません。認証情報は運営者本人の管理するコンピューター内にのみ保存されます。

Google ユーザーデータの取り扱い

本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、限定的な使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に準拠します。

権限の取り消し

Google アカウントの「サードパーティによるアクセス」設定から、いつでも本アプリへの許可を取り消せます。

お問い合わせ

本ポリシーに関するお問い合わせは、GitHub のこのリポジトリの Issues からお願いします。
